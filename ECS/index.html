Mini Project

  • The Slot Machine simulator simplifies the complexity of a casino game into an array-based logic system. It uses an Array to store different "Shape" objects, such as circles, squares, or triangles. When the user triggers the "spin" method, the program utilizes a random number generator to select indices from the array, assigning them to three distinct slot objects. This demonstrates polymorphism if the shapes inherit from a base Shape class but render differently. The win-detection logic then compares the properties of these objects to determine if a match has occurred, providing immediate feedback to the user.
  • Press "1" to Spin!.

Timer

  • Timer Application
  • Timer is a specialized utility class designed for precision and state management. It features a constructor that initializes a 10-second duration and uses methods for start(), stop(), and reset() to control the program logic. By storing the elapsed time in a private instance variable, the class maintains encapsulation, preventing external code from accidentally tempering with the clock's internal countdown. When the timer hits zero, a conditional check within the update loop triggers a visual alert, showcasing a simple yet effective use of event-driven programming

  • Tank Game
  • WASD to move, click to shoot. Collect powerups and hit rocks to increase score
  • The Tank Game is built upon a Class hierarchy where the Tank and Projectile objects interact within a coordinate system. The user controls the tank's movement and firing via methods such as instance variables. To handle the four power-ups, I utilized an ArrayList to dynamically manage their presence on the screen. Each power-up is an object of a PowerUp class, which uses encapsulation to hide its specific effect (e.g., speed boost or turret) until the tank’s hit-box intersects with it. This interaction triggers game logic that modifies the tank’s attributes in real-time, demonstrating how objects can communicate and influence each other's states.
